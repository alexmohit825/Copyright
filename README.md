# CopyRight Ops — Software Copyright Registration Platform

![Status](https://img.shields.io/badge/status-active-brightgreen)
![Type](https://img.shields.io/badge/type-single--page--app-blue)
![License](https://img.shields.io/badge/license-MIT-purple)

CopyRight Ops is a structured platform for managing software copyright registration workflows — from initial application drafting through submission tracking and certification. It provides a sidebar-driven dashboard to organize multiple copyright projects in one place.

---

## ⚖️ Features

- **Multi-Project Dashboard** — Manage multiple copyright registration projects from a persistent sidebar
- **Status Tracking** — Track each registration through Draft → In Progress → Ready → Submitted → Certified stages
- **Application Builder** — Structured forms for all required copyright registration fields
- **Status Badge System** — Color-coded visual indicators for each registration state
- **Document Management** — Organize supporting materials and code deposits per registration
- **Navigation Sections** — Dedicated views for Dashboard, New Registration, My Registrations, and Settings
- **Fixed Sidebar Layout** — Professional dark sidebar UI with section labels and notification badges
- **Responsive Cards** — Clean card components with shadow and border styling throughout

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Edge, Firefox, Safari)
- No installation, build tools, or server required

### Run Locally
```bash
git clone https://github.com/your-username/CopyRightOps.git
cd CopyRightOps
open index.html
```

### Deploy to GitHub Pages
1. Push `index.html` to your repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Live at `https://your-username.github.io/CopyRightOps`

## 📋 Registration Status Flow

```
Draft → In Progress → Ready for Submission → Submitted → Certified
```

| Status | Color | Description |
|---|---|---|
| Draft | Gray | Work in progress |
| In Progress | Amber | Actively being completed |
| Ready | Blue | Prepared for submission |
| Submitted | Indigo | Filed with copyright office |
| Certified | Green | Registration confirmed |
| Blocked | Red | Requires attention |
